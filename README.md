# 🌤️ SkyPulse — Weather & Air Quality Dashboard

A real-time weather and air quality monitoring app built with HTML5, Tailwind CSS, JavaScript, Chart.js, and the Open-Meteo REST API.

---

## ✨ Features

- **Live Weather API Data:** Real-time temperature, humidity, wind speeds, and UV index powered by Open-Meteo.
- **Air Quality Index (AQI):** Visual meter displaying PM2.5, PM10, and health indicator status.
- **24-Hour Interactive Chart:** Powered by Chart.js to graph hourly temperature trends.
- **7-Day Forecast Grid:** Daily high/low temperature forecasts.
- **Geolocation & City Search:** Search any city worldwide or use GPS geolocation.
- **Unit Toggle:** Instant conversion between Celsius (°C) and Fahrenheit (°F).
